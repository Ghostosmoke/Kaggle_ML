## 🎯 О проекте

Этот репозиторий содержит коллекцию ноутбуков Jupyter и учебных материалов, посвящённых решению практических задач машинного обучения. Особый акцент сделан на применении ML в сфере **кибербезопасности**:

| Проект | Задача | Тип данных | Модель |
|--------|---------|-----------|---------|
| 🚢 **Titanic** | Предсказание выживания пассажиров | Табличные данные | KNN + Feature Engineering |
| 🔐 **DGA Detection** | Обнаружение доменов, сгенерированных алгоритмами | Текстовые (домены) | CatBoost + 28 инженерных признаков |
| 🌐 **HTTP Malware** | Классификация вредоносного HTTP-трафика | Полуструктурированные логи | Ансамбль: LR + LightGBM |
| 🐚 **Bind/Reverse Shell** | Детекция shell-команд атакующих | Текст команд | Ансамбль: LR + RF + SVC + MNB |
| 📡 **Who's Talking** | Классификация приложений по сетевым пакетам | Временные ряды пакетов | 1D-CNN |

### ✨ Ключевые особенности

- 🔍 **Полные пайплайны**: от загрузки данных до отправки на Kaggle
- 🧠 **Объяснение моделей**: математика, параметры, сильные/слабые стороны
- 📖 **Доступный язык**: сложные концепции объясняются простыми словами
- 🛡️ **Фокус на Security**: задачи, актуальные для SOC и Threat Intelligence
- ♻️ **Воспроизводимость**: фиксация `random_state`, кросс-валидация, логирование

## 🔧 Технологии

### Основные библиотеки
```python
# Data & ML
pandas >= 1.5.0          # Работа с табличными данными
numpy >= 1.23.0          # Численные вычисления
scikit-learn >= 1.2.0    # Классические алгоритмы ML

# Boosting & Deep Learning
catboost >= 1.2.0        # Градиентный бустинг (Yandex)
lightgbm >= 3.3.0        # Быстрый градиентный бустинг (Microsoft)
tensorflow/keras         # Нейронные сети (для CNN-проектов)

# Text & Features
nltk / regex             # Обработка текста и паттернов
scipy.sparse             # Разреженные матрицы для TF-IDF

# Utilities
tqdm                     # Прогресс-бары
matplotlib / seaborn     # Визуализация
```

### Требования к окружению
```bash
# Создание виртуального окружения
python -m venv kaggle_env
source kaggle_env/bin/activate  # Linux/Mac
# или
kaggle_env\Scripts\activate     # Windows

# Установка зависимостей
pip install pandas numpy scikit-learn catboost lightgbm matplotlib seaborn tqdm
# Для глубокого обучения:
pip install tensorflow  # или torch, если используете PyTorch
```


## 📚 Образовательные материалы

### 🧠 Для продвинутых
| Файл | Что внутри |
|------|-----------|
| `Все_модели_smart.md` | Математические детали: функции потерь, оптимизаторы, регуляризация |

### 💡 Ключевые концепции, которые вы освоите
- ✅ Предобработка данных: очистка, заполнение пропусков, масштабирование
- ✅ Feature Engineering: создание признаков из текста, времени, категориальных данных
- ✅ Балансировка классов: `class_weight`, `scale_pos_weight`, SMOTE
- ✅ Валидация: кросс-валидация, StratifiedKFold, early stopping
- ✅ Ансамбли: hard/soft voting, stacking, калибровка вероятностей
- ✅ Интерпретация: важность признаков, ROC-AUC, Precision-Recall, Fβ-метрики
